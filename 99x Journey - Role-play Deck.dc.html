99x  ·  AI-native delivery
08
Plugins
Kalana answers

“How do new capabilities get added?”

01
A plugin is a folder of markdown and JSON, not compiled code. Capability is declared, not built.
02
One manifest is required. Commands, skills, agents, hooks and MCP servers are all optional.
03
They fire from delivery events — a pull request, an issue, a work item — not only from someone typing a prompt.
04
Twelve official plugins today, each doing one job: review, impact, tests, docs, performance, archaeology.

“How do you know any of it works?”

01
We model the process first, then measure against it, so every number knows which step it belongs to.

04
The caveat: measure tokens alone and teams optimise for cheap prompts. Usage is always read next to delivery outcomes.
